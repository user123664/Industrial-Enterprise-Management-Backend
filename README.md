# 智云工控 - 工业企业运营管理后台

## 项目简介

面向工业制造企业的综合运营管理后台系统，涵盖设备管理、生产工单、质量检测、人员管理、权限控制等核心业务模块，帮助企业实现生产数据可视化和管理数字化。

## 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | Vue 3 (Composition API) |
| UI 组件库 | Element Plus |
| 构建工具 | Vite 5 |
| 状态管理 | Pinia |
| 路由 | Vue Router 4 |
| HTTP 请求 | Axios |
| 数据可视化 | ECharts 5 |
| 工具库 | Day.js、NProgress |

## 功能模块

### 1. 登录与权限
- 账号密码登录，Token 模拟鉴权
- 基于 RBAC 模型的动态路由
- 按钮级权限控制（`v-role` 自定义指令）
- 路由守卫拦截未授权访问

### 2. 数据看板
- 产量/设备/工单/合格率概览卡片
- ECharts 产量趋势折线图（可切换产量/不良品）
- 设备状态饼图
- 各车间产能对比柱状图
- 实时告警列表

### 3. 设备管理
- 设备列表：搜索筛选、分页、CRUD
- 设备状态标签化展示
- 利用率进度条
- 维护记录查询

### 4. 工单管理
- 工单全流程管理
- 完成进度可视化
- 状态统计卡片
- 优先级标签

### 5. 质量检测
- 检测报告列表
- 合格率趋势图
- 不良品类型分布图
- 统计数据卡片

### 6. 人员管理
- 员工 CRUD
- 部门/岗位筛选

### 7. 系统设置
- 角色管理（权限树分配）
- 操作日志

## 技术亮点

1. **动态路由 + RBAC 权限模型**：根据用户角色动态生成路由，实现菜单级和按钮级双重权限控制
2. **ECharts 数据可视化**：多种图表类型，支持窗口自适应和数据联动
3. **封装通用 CRUD 组件模式**：搜索 -> 表格 -> 弹窗表单 -> 分页的标准化流程
4. **标签页导航 + keep-alive**：多页面标签管理，组件缓存提升体验
5. **Vite 构建优化**：路由懒加载 + 手动 chunk 分包，减小首屏体积
6. **自定义指令 `v-role`**：声明式按钮级权限控制
